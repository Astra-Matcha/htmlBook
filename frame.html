지은이: 홍길동

머리말

전자책1)에서는 종이책의 하단 주석처럼 본문 속 번호를 눌러 추가 설명을 바로 확인할 수 있습니다.

본문 중 붉은색 위첨자 번호를 클릭해 보세요. 하단에 각주가 열리며, 열린 각주를 다시 누르면 닫힙니다.

1) 전자책(eBook): 종이책의 내용을 디지털 파일 형태로 변환하여 PC, 스마트폰, 전용 단말기 등에서 읽을 수 있도록 만든 책.
- 1 -

1장. 각주 활용하기

전문 서적이나 논문, 번역서에서는 독자의 흐름을 끊지 않기 위해 부연 설명을 미주2) 대신 각주3)로 처리하는 경우가 많습니다.

한 페이지 안에 여러 개의 각주를 넣을 수도 있습니다. 필요한 번호만 골라서 펼쳐 볼 수 있어 지면이 깔끔하게 유지됩니다.

2) 미주(Endnote): 책이나 장의 맨 뒷부분에 한꺼번에 모아 놓는 주석.
3) 각주(Footnote): 해당 본문이 있는 페이지의 맨 아래쪽에 달아 놓는 주석.
- 2 -

2장. 작성 방법

본문에는 <span class="fn-ref" data-fn="fn-4">4)</span>를 넣고, 같은 페이지의 .footnotes 안에 동일한 id="fn-4"를 가진 설명 박스를 추가하면 자동으로 연결됩니다4).

4) 연결 규칙: data-fn 값과 하단 .fn-item의 id 값만 서로 일치시키면 됩니다.
- 3 -

마치며

각주를 클릭할 때는 책장이 넘어가지 않도록 처리되어 있어, 독자가 설명을 편하게 읽고 닫을 수 있습니다.
