제1장. 자바스크립트 없는 웹

이 전자책 뷰어는 단 한 줄의 JavaScript도 사용하지 않았습니다. 보안 정책으로 스크립트가 차단된 환경이나, 구형 브라우저, 혹은 단일 HTML 파일로 문서를 배포할 때 매우 안정적으로 작동합니다.

상단의 '세피아' 버튼이나 '가+' 버튼을 눌러보세요. CSS의 가상 클래스(:checked)만으로 스타일이 즉시 변경됩니다.

제2장. CSS 상태 관리의 원리

HTML의 <input type="radio"> 요소는 같은 name 속성을 가진 항목 중 오직 하나만 선택되는 특성을 가집니다. 이는 전자책에서 '현재 열려 있는 페이지'를 관리하는 완벽한 도구가 됩니다.

<label for="p4"> 태그를 버튼처럼 디자인하면, 사용자가 버튼을 클릭할 때마다 보이지 않는 라디오 버튼의 상태가 바뀌며 다음 페이지가 화면에 나타납니다.

제3장. 페이지 확장 방법

새로운 페이지를 추가하는 방법은 매우 간단합니다. 상단의 라디오 버튼 목록에 id="p5"를 추가하고, CSS의 페이지 표시 규칙에 #p5:checked ~ .ebook-wrapper #page-5 한 줄만 더해 주면 됩니다.

이미지, 표, 인용구 등 일반 HTML에서 지원하는 모든 요소를 본문 안에 자유롭게 배치할 수 있습니다.
